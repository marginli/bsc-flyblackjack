## 說明影片（2026-10-16）

管線沿用 VFB：`video_slides.py`（COURSE 設定＋投影片要點＋旁白稿）→ `make_video.py`（Chrome 截圖 → 本機合成旁白 → ffmpeg）
→ `video_check.py`（投影片上每一點旁白有沒有講到）→ `video_verify.py`（影音同步用 silencedetect 算；辨識回填用 ~/.venvs/asr 的 faster-whisper，CPU 跑）。
`make_video.py` 多了 SAY_FIX：旁白稿寫原名與阿拉伯數字，送 TTS 前才換成唸得對的寫法（字幕、video_check、頁面對照看到的都是原稿）；
負號「−」要轉「負」（直接送會被唸成「貓」）。本課的縮寫逐一用辨識回填驗過（2026-10-16，三輪）：
不拆才對的：KC、PAM、CEM、Dino、Doom、GitHub、conda、md5、FlyWire、兩字母＋數字的代號（FF1、E1、BJ1、X1）；
要改寫的：DNa02 → D N A 零二、AOTU019 → AOTU 零一九、LC10a → LC 十 a、MBON → M B O N、DAN → D A N、PPL1 → P P L 一、
PN → P N、README → read me、MaleCNS → Male C N S、ViZDoom → Doom 引擎（唸不出 V）、Hz → 赫茲。
長度以 VFB 的 4.4 字/秒估：Doom 2,624 字 → 9 分 50 秒（11 張）、21 點 3,236 字 → 12 分 12 秒（14 張）。
